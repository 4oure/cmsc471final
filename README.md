# The Anatomy of a Scoring Drive

## Project Description

**The Anatomy of a Scoring Drive** is an interactive data visualization project that explores how NFL scoring drives develop play by play. Instead of only showing the final result of a drive, 
this visualization lets users follow the sequence of plays, field position changes, expected points added (EPA), and win probability throughout a drive.

The goal of this project is to make football drive progression easier to understand by combining play-by-play data with visual storytelling. 
Users can select a team, week, game, and drive, then explore how each play contributes to the overall outcome of the drive.

## Features

- Interactive dropdown controls for selecting team, week, game, and drive
- Play-by-play drive log
- Football field visualization showing drive progression
- EPA visualization showing the impact of each play
- Win probability visualization
- Drive summary statistics

## Data Source

This project uses NFL play-by-play data from **nflfastR**, a public NFL analytics dataset. 
The data was preprocessed into JSON format so that it could be loaded directly into the D3 visualization.

Data source:  
https://www.nflfastr.com/

The included dataset focuses on the 2025 NFL regular season play-by-play data and organizes plays by game, team, and drive.
